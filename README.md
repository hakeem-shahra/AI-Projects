# 🎓 Student Performance Prediction

## 📌 About the Project
Student Performance Prediction is a Machine Learning project designed to analyze student academic data and predict their academic performance based on several educational factors.

The system uses student-related features such as attendance, midterm scores, and study hours to predict whether a student is likely to succeed academically.

## 🎯 Project Objectives
- Analyze student academic performance.
- Apply Machine Learning algorithms to educational data.
- Predict student success using trained models.
- Support data-driven educational insights.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
- Data Visualization

## 🤖 Machine Learning Models
The project explores multiple classification algorithms, including:
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

## 💡 Project Goal
The main goal is to demonstrate how Artificial Intelligence and Machine Learning can be used to understand student performance and help identify students who may need additional academic support.
